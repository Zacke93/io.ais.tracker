## Styrande principer

1. **Instrument före produkt** (fas A ändrar ingen produktbana; hårt noll-diff-krav).
2. **En fix — en commit — full grindkörning.** Sekventiell merge i fastlagd ordning; per-fix riktad jest + regressionslås.
3. **Riskklasser:** GRÖN = noll facitdiff. GUL = diff tillåten endast med rådataverifiering per post + `REGEN_DISTRIBUTIONS=1`-omlåsning i samma commit + corpora.js-not. RÖD = därutöver PRE-fusions-/rådatafacitbevis, parkörningar och dokumenterat revert-kriterium (isolerad commit).
4. **Diff-av-diff för interaktionspar** (§Interaktioner): kombinationens facitdiff ska vara exakt unionen av de enskilda; varje ny post = stopp.
5. Om en fix facit-fälls oåterkalleligt (kan inte göras kirurgisk): återkalla den, dokumentera i etappdokumentet, gå vidare — helheten stannar inte.
